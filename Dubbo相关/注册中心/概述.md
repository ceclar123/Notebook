注册中心是 Dubbo 服务治理的核心组件，Dubbo 依赖注册中心的协调实现服务（地址）发现，自动化的服务发现是微服务实现动态扩缩容、负载均衡、、流量治理的基础。Dubbo 的服务发现机制经历了 Dubbo2 时代的接口级服务发现、Dubbo3 时代的应用级服务发现

以 Spring Boot 开发为例，在 application.yml 增加 registry 配置项目

```yaml
dubbo
 registry
  address: {protocol}://{cluster-address}
  # address: nacos://localhost:8848
  # ddress: nacos://localhost:8848?backup=localshot:8846,localshot:8847
  # address: zookeeper://127.0.0.1:2181
  # address: zookeeper://10.0.0.1:2181?backup=10.0.0.2:2181,10.0.0.3:2181
 config-center: 
   address: zookeeper://10.0.0.1:2181?backup=10.0.0.2:2181,10.0.0.3:2181 
 metadata-report: 
   address: zookeeper://10.0.0.1:2181?backup=10.0.0.2:2181,10.0.0.3:2181
```
 
 Dubbo 目前支持的主流注册中心实现包括：
- Zookeeper
- Nacos
- Redis
- Consul
- Etcd
- 更多实现
